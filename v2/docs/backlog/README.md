# Backlog — what is open, and what is merely wanted

| document | what it is |
|---|---|
| [TODO.md](TODO.md) | what is still open, grouped by what it would take to close it — a dated deadline, a code change first, a live check first, or a decision from the player |
| [IDEAS.md](IDEAS.md) | the wider backlog: captured, not designed, each with a rough size and a "decide first" flag |

Both are lists rather than [plans](../plans/README.md): a plan is what an idea becomes once it has a
design and a verdict.

# Records — what happened, and when

Dated, append-only, and never edited to stay current: a record is true of the moment it describes, and
rewriting one to match today is how a history stops being evidence.

| document | what it is |
|---|---|
| [PROGRESS.md](PROGRESS.md) | the dated log — one entry per landed victory, newest first. The reasoning behind each change lives here, not in the code comments |
| `RELEASE-vX.Y.md` | the notes for each release, each with its verified / not-verified table |
| [HANDOVER.md](HANDOVER.md) | a session handover prompt, kept as the record of that session |

What is still **open** is not here — that is [../backlog/TODO.md](../backlog/TODO.md).

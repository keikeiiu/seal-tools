# Game knowledge

**Not project documentation.** Nothing here describes the tool or how it is built. This folder is for
facts about **the game itself** — mechanics, NPCs, quests, item behaviour — collected because they
explain why a tool behaves the way it does, or because they were needed to design one and would be
expensive to look up again.

The distinction matters for two reasons:

- **These are not ours.** The text is the publisher's. Where a page is quoted, the source URL and the
  date it was read are on the page — game guides change, and a copied fact with no date is a fact
  nobody can check.
- **Nothing here ships.** The tool's docs are `v2/docs/`; these are reference material for reading, not
  a specification anything is built against. If a tool depends on one of these facts, the *tool's* docs
  should say so rather than pointing here.

Where the server matters, it is stated. These guides come from the **Korean** service
(`sealonline.co.kr`); the Taiwanese service the tool is calibrated against may differ, and a difference
is worth recording rather than assuming away.

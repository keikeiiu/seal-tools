Interactive Archify pages generated from the seal-tools v3 source at commit e4789da. Each page is self-contained with inline SVG: theme switching, zoom, search, path focus and PNG/JPEG/WebP/SVG/WebM export. The eight tool flows match the v2 set; calibration and the four system views are new for v3.

Run flows

  • Suite overview Flutter shell, protocol, supervisor, tool decision/runner, game and Arduino board. Start here
  • Calibration Capture + assign, draw mark/session, validate, save + derive, verify and delete. Calibrate
  • Buy Start gate, ordered transaction plan, focus/scroll, count, one pass. Shop
  • Sell Slots argument, selection/cap plan, highest-slot-first, MAX/Enter. Shop
  • Magic Tuner Countdown/guard, click/Enter, OCR read, grade/filter decision and stops. Tuner
  • Gem Composer Select, combine, empty-result read, streak gate, advance, all grades done. Gem
  • Quest Hand-in Validate, position + cursor guard, replay steps, loop verdict. Quest
  • Pet Feeder Preflight, row reads, schedule, visit/reload, wait, row drop. Resident
  • Skill Spammer Tick, yield gate, combo/single walk, key writes, exits. Spammer

System views

  • Runtime architecture Shell ↔ core process, Rust crates, Win32/OCR/board, game and Arduino. Architecture
  • Tool run lifecycle Idle → starting → running → stopping → finished, with refusal/error exits. Lifecycle
  • Start / stop sequence Shell → supervisor → tool → board, Stop/cancel, tool.finished. Sequence
  • Config ownership + writes Defaults/setup/machine → merged config → readers → one write gate → file + event. Dataflow

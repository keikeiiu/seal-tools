The OCR read is the job.
Give it the room.

The Tuner mini bar currently puts Grade / Left / Try chips beside the three OCR attribute results. The OCR values are what the player is actually inspecting between attempts, so this study gives them the full-width main area and moves the three run metrics down into the footer, next to the countdown and Stop.

Why move them? Grade / Left / Try are course corrections, not the primary read. Giving the OCR attributes one full-width line each improves scanning and removes the side-by-side squeeze; the metrics still stay visible in the footer, so nothing is hidden.

Rules for the reorder

Keep the bar’s one-action rule; only the hierarchy changes.
1OCR attributes own the middle

Three lines, full width, one name=value per line. No cards. Normal attributes stay bright on-surface; only attributes that satisfy the enabled filter use the blue primary colour.

2Metrics move to the footer

Grade / Left / Try become compact chips before the countdown and Stop. They stay visible but no longer compete with the OCR read.

3Filter stays full width

The reason line keeps its own row under the attributes; the full filter text remains in the tooltip.

4Finished/error keep the shape

Outcome sentence replaces the action line; OCR lines remain if the last read exists; the footer becomes Quick dock + Full window.

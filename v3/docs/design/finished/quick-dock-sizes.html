SSeal Tools v3 Design study
Quick dock · size presets

Same dock. Three sizes.
Type that scales with it.

The larger window option resized the dock, but every label, icon and Start button stayed at the Standard pixel size. The result is a roomier frame with tiny controls floating in it. This study keeps the same dock shape and introduces one metrics table per preset: the window and the UI scale together, while the action column stays fixed so Start/Stop labels line up across every row.

The rule
Window 0.90 / 1.00 / 1.25×
Type 0.96 / 1.00 / 1.15×
Controls 0.93 / 1.00 / 1.21×
Density same tile order
What is actually off: the window factor is applied in DockSize.scale(), but tile typography and button heights are constants. A Large dock is 1.25× wider while its Start button is still 64 × 28 px with a 12 px label — so the button text reads smaller than the title and sits on a different visual centre line than the row.

04

Four implementation rules

These remove the “small text in a big frame” look without turning the dock into a different component.
1One metrics object per preset

Derive DockMetrics from DockSize once. Pass it into the header, tile, footer and collapsed form instead of hard-coded fontSize: 13 and height: 28.

2Fixed action column, fixed row height

Wrap Start in a column of --action-width and centre it in a row of --row-height. Start and Stop never change the column width; every row's action edge is identical.

3Type scales by a type ramp, not the window factor

Window 1.25× is room, not a zoom. Use 15 px titles and 13.5 px button labels for Large, and keep Compact labels at ≥11.5 px even though the window is 0.9×.

4Keep the status out of the action geometry

The running chip belongs in the title line (or a reserved slot). It must never push the Start button off the action column or change the row height.

05

Flutter mapping

A small metrics layer keeps the three presets consistent with the existing dock code.
// one source of truth; DockSize stays the persisted preset
final m = DockMetrics.forSize(model.dockSize);

// tile
SizedBox(height: m.rowHeight, child: Row(children: [
  IconTile(size: m.iconTile, iconSize: m.iconSize),
  Expanded(child: Text(title, style: m.titleStyle)),
  SizedBox(width: m.actionWidth, height: m.actionHeight,
    child: FilledButton(style: FilledButton.styleFrom(textStyle: m.actionTextStyle))),
  IconButton(minimumSize: Size.square(m.optionsSize)),
]));

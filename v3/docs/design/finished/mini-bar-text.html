SSeal Tools v3 Mini bar · text design

Read the run.
Not a log line.

The old 460 × 168 bar devoted five lines to one ` · `-joined sentence: grade, count, attempt, attributes and filter ran together with the action message. The redesign keeps the action sentence as the primary line, turns live facts into labelled chips, and gives a long Filter its own line. The countdown and one primary action anchor the bottom.

03

Text rules and type scale

The bar is a status surface: one primary sentence, scannable facts, one action.
1Primary line is the action/outcome

Tool name 14 px · action line 13 px semibold. The core’s message is never replaced by the fact summary; with no facts it may wrap to two lines.

2Metrics are chips; attributes are text

Grade/left/try use labelled chips (7.5 px label, 10.5 px value). OCR attributes stay one name=value line each, with no card; an attribute named by the enabled filter is tinted with the primary colour, the rest stay neutral.

3Long Filter gets its own line

The filter result can be a sentence, so it is a full-width, one-line ellipsized row with a FILTER label and the full text in the tooltip.

4Footer is stable

Clock icon + countdown on the left, one fixed-size primary action on the right: Stop while active, Quick dock + Full window when finished.
